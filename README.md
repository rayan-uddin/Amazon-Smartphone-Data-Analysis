# Amazon Smartphone Data Analysis

## Project Overview

This project analyzes smartphone data scraped from Amazon.
The dataset was cleaned to remove irrelevant products and
then explored using Python.

## Dataset

The dataset contains information about:

- Device name
- Price
- Rating
- Brand (extracted from device name)

## Data Cleaning

The data cleaning process included:

- Removing duplicate records
- Handling missing values
- Converting price and rating to numeric values
- Removing non-smartphone products
- Extracting brand names from device names

## Analysis

The following analyses were performed:

- Smartphone price distribution
- Rating distribution
- Number of smartphones by brand
- Average price by brand
- Average rating by brand
- Price vs rating relationship

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
